Utility Bill Management System
Project Overview

The Utility Bill Management System is a Java-based desktop application developed using Swing and AWT. It helps users manage utility bills efficiently by tracking paid and unpaid bills, highlighting overdue bills, and providing search, filter, and sorting functionalities.
This project is designed to demonstrate core Java concepts through a real-world application.

Features

Add, edit, and delete utility bills

Mark bills as paid or unpaid

Toggle paid/unpaid status easily

Search bills by name, date, description, or status

Filter bills (All / Paid / Unpaid)

Sort bills by amount or due date

Highlight paid bills in green 

Display total, paid, and unpaid bill amounts

Persistent data storage using file handling

Technologies Used

Java

Swing & AWT

Object-Oriented Programming

File Handling

How to Run the Project
Method 1: Using JAR file

Double-click UtilityBillApp.jar

The application will launch automatically
Method 2: Using Command Prompt
javac *.java
